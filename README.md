# 🌙 iLmiFa — Commercial Multi-Tenant Madrasa Management SaaS Platform

iLmiFa is a state-of-the-art commercial multi-tenant SaaS platform engineered specifically for modern Islamic educational institutions and Madrasas worldwide.

---

## 🌟 Core Architecture & Features

1. **iLmiFa Core Super Admin Dashboard**: Centralized management of Madrasa tenants, module feature flags, custom domain DNS mappings, and platform analytics.
2. **Tenant Portal Routing**: Dynamic tenant resolution supporting relative paths (`/m/:tenantSlug/login`), custom domain mapping, and subdomains.
3. **Role-Based Access Control (RBAC)**: Enforces strict permissions across Super Admin, Principal, Teacher, and Parent accounts.
4. **Secondary Authentication Engine**: Enables Super Admins and Principals to provision new user accounts without losing their active session.
5. **Multi-Child Parent App**: Single parent account links multiple students with 1-click child switcher pill navigation.
6. **Progressive Web App (PWA)**: Standalone PWA installability with offline shell capabilities.

---

## 🛠️ Technology Stack
- **Frontend**: React 18 + TypeScript + Vite
- **Styling**: Modern Custom CSS Design System
- **Backend & Auth**: Firebase Auth + Cloud Firestore
- **PWA**: Web App Manifest & Service Worker
